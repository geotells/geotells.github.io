About this app

On street-level photos, the clues to where you are hide in the details: the letters on the signs, the plates, the side of the road the cars drive on. GeoTells teaches them in short lessons, a few minutes a day, and a daily challenge to play with friends.

How to install it

GeoTells is not on Google Play yet, so Android asks a few extra questions the first time. It is safe: say yes to them.

  1. Tap Download for Android. If the browser warns that the file could be harmful, tap Download anyway.
  2. Open GeoTells.apk: from the download notification, or from the Files app, in Downloads.
  3. If it says your phone is not allowed to install unknown apps from this source, tap Settings, turn on Allow from this source and go back. This lets your browser (or the Files app) install apps; you can turn it off afterwards.
  4. If a security feature of your phone blocks the installation (some brands include an automatic blocker), turn it off for a moment in Settings › Security, install GeoTells and turn it back on.
  5. If Google Play Protect says it does not know the app, tap More details and then Install anyway.
  6. Tap Install, then Open. To update it later, download it again from here and install it over the old one: your progress stays.
